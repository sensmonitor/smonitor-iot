# v0.2.1 — ESP-IDF 5.5.6

This maintenance release updates the development and CI environment from
ESP-IDF 5.5.5 to ESP-IDF 5.5.6. There are no application or configuration
changes.

## Changes

- ESP-IDF updated from 5.5.5 to 5.5.6, including the dependency lock file.
- CI builds all board profiles with ESP-IDF 5.5.6.
- README, CONTRIBUTING and ROADMAP reference ESP-IDF 5.5.6.

## Validation and limitations

- Local ESP-IDF 5.5.6 compilation passed with no compiler warnings for the
  ESP32-S3 profile and the LilyGO SIM7000G (ESP32) profile, including the
  application partition size check.
- Component dependencies are unchanged: `smonitor-modem` 0.1.6,
  `smonitor-i2c` 0.1.1, `esp_modem` 1.4.3 and `esp_websocket_client` 1.8.0.
- Runtime validation on hardware is pending for ESP-IDF 5.5.6.

## Upgrading

Install ESP-IDF 5.5.6 and select it in the IDE or activate it in the shell.
Use a fresh build directory so no objects built with ESP-IDF 5.5.5 are
reused.
