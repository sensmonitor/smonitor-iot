# v0.1.5 — Custom ESP32-S3 profile and ESP-IDF 5.5.5

This release adds a custom ESP32-S3 N8R8 UART modem configuration and updates
the development and CI environment to ESP-IDF 5.5.5.

## Changes

- New `examples/generic_esp32s3_uart_modem/sdkconfig.defaults` profile:
  8 MB flash, 8 MB Octal PSRAM at 80 MHz, UART TX/RX GPIO4/GPIO5 at 115200,
  PWRKEY GPIO46 with a 100 ms active-high pulse and 10-second startup delay,
  and I2C SDA/SCL GPIO3/GPIO2.
- A7670E integration example using the existing SIM7670 modem profile.
- Original generic ESP32/SIM7000 example preserved.
- ESP-IDF updated from 5.5.4 to 5.5.5, including the dependency lock file.
- CI expanded to five board configurations with explicit targets and defaults.
- Configuration documentation explains sdkconfig precedence and how to apply
  defaults to a fresh configuration.

## Validation and limitations

- Local ESP-IDF 5.5.5 compilation with the custom ESP32-S3 configuration and
  Octal PSRAM enabled passed, including the application partition size check.
- The custom configuration was checked independently from a fresh sdkconfig.
- A7670E uses a compatibility profile; this release does not add a dedicated
  A7670 driver or validated A7670-specific GNSS and 2G support.
- PSRAM runtime initialization must be verified on the target hardware.
- Existing LilyGO PSRAM settings are preserved. Match Quad/Octal mode to the
  exact module variant when selecting a profile.

## Configuration

Existing sdkconfig values take precedence over defaults. Editing
sdkconfig.defaults.local alone does not overwrite an existing configuration.
Use menuconfig or generate a fresh sdkconfig to apply the intended settings.
GPIO values in the custom example must match the actual wiring.
